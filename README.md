# 🚀 Explore Space

## 📌 About the Project
Explore Space is an interactive web application developed using AngularJS. It helps users explore planets and learn interesting facts about space through an engaging and user-friendly interface.

## ✨ Features
- 🌍 Explore different planets and view their details.
- 🧠 Interactive space quiz.
- ⭐ Add planets to favourites.
- 🌌 Attractive space-themed user interface.
- 📱 Responsive design for different screen sizes.

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript
- AngularJS

## 🎯 Project Objective
The main objective of this project is to provide an interactive platform for learning about planets and space while demonstrating the use of AngularJS.

## ▶️ How to Run
1. Clone or download this repository.
2. Open the project folder.
3. Locate the `index.html` file.
4. Open it in a web browser.
5. If required, use the Live Server extension in Visual Studio Code.
